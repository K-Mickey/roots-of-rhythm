# EPIC-010: точка входа, каталоги и поиск

Статус: `draft`

Tracker: [GitHub issue #4](https://github.com/K-Mickey/roots-of-rhythm/issues/4). Первая story: [STORY-003 #24](https://github.com/K-Mickey/roots-of-rhythm/issues/24).

## Пользовательский результат

Visitor находит, с чего начать, и добирается до нужного опубликованного материала через главную, списки и поиск — без авторизации и без зависимости от проигрывателя.

## Поддерживаемая ценность

- понятная точка входа вместо «знать UUID Genre»;
- навигация к жанрам, позднее — к исполнителям, записям, танцам, историям и карте по мере появления их public routes;
- проверяемая статистика корпуса — только когда соответствующие сущности публичны;
- единый поиск — когда есть что искать помимо трёх Genre.

## Эволюция главной

Три стадии зафиксированы Product Owner 2026-08-19 и описаны в [home-evolution.md](home-evolution.md):

1. **минимальная** — крупное название и короткое описание по центру, без жанров и дашборда;
2. **базовая корпусная** — краткая информация и `HomeStatistics` по опубликованному корпусу;
3. **полная discovery** — каталоги, поиск и вход на карту; без редакционных подборок.

## Stories

1. [STORY-003: открыть минимальную главную](story-003-minimal-home/README.md) — `done`.
2. Показать список опубликованных Genre — draft-кандидат после HOME-0; отдельная страница, не главная.
3. Базовая главная со статистикой и навигацией по типам сущностей — после появления соответствующих public pages (EPIC-002/004/011 и карта EPIC-003 по мере готовности).
4. Списки и фильтры прочих каталогов — не раньше, чем сущность имеет public page.
5. Единый поиск — после нескольких типов опубликованных сущностей.

Stories 2–5 — границы планирования, кроме STORY-003.

## Не включает

- персонализацию и «продолжить изучение»;
- редакционные подборки знаковых материалов ([future-scope](../../product/future-scope.md));
- конструктор блоков главной;
- Elasticsearch как обязательный первый search engine;
- локализацию.

## Зависимости

- опубликованный Genre и STORY-001/002 для ссылок на detail pages;
- [ADR-0004](../../decisions/0004-application-stack.md) application shell.

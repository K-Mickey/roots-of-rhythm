# Эволюция главной страницы

Статус: `accepted`

Владелец: Product Owner.  
Epic: [EPIC-010](README.md).

Решение 2026-08-19: главная развивается тремя стадиями по мере появления публичных сущностей. Статистика и дашборды не входят в первую поставку.

## HOME-0 — минимальная

Story: [STORY-003](story-003-minimal-home/README.md).

Visitor открывает `/` и понимает назначение продукта. Ориентир по жанрам — отдельная страница каталога, не главная.

Есть:

- крупный `h1` с именем продукта по центру вместе со слоганом «История музыки для тех кто танцует и слушает»;
- header identity ведёт на `/`, а не на stub `#`.

Нет:

- списка Genre и ссылок на `/genres/{id}`;
- счётчиков, `HomeStatistics`, графиков;
- навигации к Performer, Group, Recording, Dance, Stories, карте;
- поиска, фильтров, редакционных подборок, персонализации.

## HOME-1 — базовая корпусная

Планируется отдельной story EPIC-010, когда есть что считать и куда вести кроме Genre.

Соответствует прежней формулировке [mvp-scope «Главная»](../../product/mvp-scope.md): назначение продукта, базовая навигация по **уже существующим** public routes, проверяемая статистика только опубликованных объектов.

`HomeStatistics` (жанры, исполнители, записи, танцы, позднее истории/связи/источники) появляется здесь. Ссылка в nav не показывается, пока нет public page этого типа.

Не требует конструктора блоков и «знаковых материалов».

Зависит от: EPIC-002 (Performer/Group/Recording), EPIC-004 (Dance), EPIC-011 (Stories) и/или EPIC-003 (карта) — каждый блок независимо, по факту route.

## HOME-2 — полная discovery

Планируется позже в EPIC-010 (+ вход в EPIC-003).

Добавляет к HOME-1:

- списки/каталоги с поиском и базовыми фильтрами по типам MVP;
- заметную точку входа на карту, когда карта существует;
- сохраняет минимализм: главная не становится редакционной витриной.

Не входит даже в HOME-2 (остаётся [future-scope](../../product/future-scope.md)):

- знаковые материалы и методология знаковости;
- стартовые guided journeys;
- персональные рекомендации.

## Соответствие epics

| Стадия | Epic | Что разблокирует |
|---|---|---|
| HOME-0 | EPIC-010 STORY-003 | точка входа: название и описание, без каталога |
| HOME-1 | EPIC-010 | статистика и nav по мере EPIC-002/003/004/011 |
| HOME-2 | EPIC-010, вход EPIC-003 | поиск, каталоги, карта как discovery |

EPIC-001 владеет страницей Genre и связями между Genre, не главной. STORY-002 даёт переходы relation → Genre. HOME-0 даёт `/`. Каталог всех Genre — отдельная story EPIC-010 после HOME-0.

# UI contract: каталог и опубликованная песня

Статус: `accepted`

Story: [STORY-007](README.md).  
Shell: [design STORY-001](../../epic-001-genre-exploration/story-001-view-published-genre/design.md).

## Страница `/songs`

`main` содержит единственный `h1` «Песни» и список published MusicalWork. Каждое имя — визуально отличимая ссылка `/songs/{id}`. Пустой список сохраняет заголовок без плейсхолдеров. Ошибка загрузки использует `PageError`, `retryHref="/songs"`.

## Страница `/songs/{id}`

Единственный `h1` — canonical title Work.

Если данные есть, последовательно показываются:

1. aliases, описание, период и внешние идентификаторы;
2. «Авторы» — Person links с точной ролью WorkCredit;
3. «Классификация произведения» — links на published Genre/Style;
4. «Связанные произведения» — тип WorkRelation и ссылка на related Work;
5. «Текст» — горизонтальный переключатель опубликованных LyricsVersion.

Пустые секции не рендерятся. Отсутствие авторов или текста не является ошибкой и не заменяется «Неизвестно».

### Версии текста

- Доступное имя элемента: язык и label; одинаковые языки различаются label.
- Machine translation получает видимую пометку «машинный перевод».
- Если body недоступно по rights/access policy Source, UI показывает metadata и безопасное сообщение, но не внутренние rights notes.
- Выбор обновляет `?text=<id>` без полной перезагрузки и поддерживает back/forward.
- Невалидный или непубличный text id не раскрывает данные и выбирает первую версию в порядке API.
- Переключатель доступен с клавиатуры и сообщает выбранное состояние assistive technology.

До STORY-008 секции «Жанры исполнений», Recording и «Послушать» отсутствуют.

## Header и главная

Header получает «Песни» → `/songs` после существующих публичных каталогов. На `/` нет списка песен и ссылок `/songs/{id}`.

## Ошибки

Ошибка overview API, кроме 404, показывает `PageError`. Неизвестный или непубличный Work использует общий not-found «Материал не найден».

## Не входит

Recording, правая колонка исполнений, жанровые фасеты, плеер, поиск, Editorial UI и локализация всего интерфейса.

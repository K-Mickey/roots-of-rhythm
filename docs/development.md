# Разработка

Статус: `planned`; application stack принят, команды появятся после scaffolding.

До написания application code выполнить обязательный [GitHub delivery workflow](roadmap/delivery-workflow.md): создать Project, настроить milestone и перенести утверждённую работу из `docs/specs/`.

После инициализации проекта записать только реально работающие команды:

```text
setup: TBD
run: TBD
format: TBD
lint: TBD
typecheck: TBD
test: TBD
build: TBD
```

Для каждой команды указать рабочую директорию, необходимые сервисы и ожидаемый результат.

# No assert in production

> Запрет assert для production-проверок

- Не использовать `assert` для валидации пользовательских данных, авторизации, целостности данных и ожидаемых runtime-ошибок.
- Не полагаться на `assert` для побочных эффектов.
- Использовать явное условие и подходящее доменное, validation или infrastructure исключение.
- Допускать `assert` только в тестах и в доказуемо внутренней проверке инварианта, если проект это разрешает.

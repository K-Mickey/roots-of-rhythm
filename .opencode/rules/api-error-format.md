# Ошибки API

> Единый безопасный формат ошибок API

Возвращать стабильную структуру с `code`, `message`, опциональными `details` и `request_id`.

- `code` является стабильным машинным идентификатором.
- `message` безопасен для пользователя и не содержит внутренних деталей.
- Ошибки валидации указывают конкретное поле и причину.
- Не возвращать stack trace, SQL, секреты, пути файлов и сообщения внутренних SDK.
- Сопоставлять доменные ошибки с HTTP только на транспортной границе.
- Логировать диагностический контекст с request ID, не дублируя секреты.

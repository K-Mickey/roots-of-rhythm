# UI components

> Конвенции UI-компонентов и доступности
> Область применения: `**/*.{tsx,jsx,vue,svelte}`

- Использовать ближайший по смыслу Mantine component и настраивать его через theme/component API до создания wrapper или custom control.
- Не обходить Mantine theme случайными hex-цветами, spacing и typography values; новый token добавлять только при повторяемом design requirement.
- Компонент отвечает за одну понятную часть интерфейса.
- Использовать семантическую разметку, label, keyboard navigation и видимый focus.
- Явно обрабатывать loading, error, empty и success состояния.
- Не копировать серверные данные в локальное состояние без необходимости.
- Не использовать effect для вычисления значения, которое можно получить при render.
- Не создавать универсальный компонент из одного частного случая.
- Сохранять существующую дизайн-систему и проверять UI визуально.

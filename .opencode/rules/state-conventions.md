# State

> Правила локального, серверного и глобального состояния фронтенда
> Область применения: `**/*.{ts,tsx,js,jsx}`

- Хранить состояние максимально близко к потребителю.
- Разделять серверное состояние, UI-состояние и состояние формы.
- Не дублировать данные, которые можно вычислить из существующего source of truth.
- Глобальный store вводить только для состояния с несколькими независимыми потребителями.
- Сохранять детерминированные переходы и явно обрабатывать ошибки и отмену запросов.
- Не добавлять библиотеку управления состоянием без доказанной потребности.

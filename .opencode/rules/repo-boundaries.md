# Repository boundaries

> Границы репозитория, модулей и пользовательских изменений

- Устанавливать корень репозитория до выполнения Git-команд и изменений.
- Не переносить изменения между репозиториями и не коммитить вложенный репозиторий из родительского.
- Не изменять файлы вне текущего проекта без явного запроса.
- Сохранять незнакомые и незакоммиченные изменения пользователя.
- Не выполнять destructive Git-команды без точного разрешения.
- Не создавать новый сервис, пакет или репозиторий без подтверждённой границы ответственности.
- Общую функциональность выносить только при наличии нескольких реальных потребителей.

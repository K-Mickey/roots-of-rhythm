# Create ADR

1. Определить конкретное решение и силы, которые на него влияют.
2. Описать текущий контекст без подгонки под предпочитаемый вариант.
3. Сравнить минимум две жизнеспособные альтернативы, включая «ничего не менять», когда применимо.
4. Оценить простоту, стоимость, риски, безопасность, эксплуатацию и обратимость.
5. Записать выбранное решение, причины, положительные и отрицательные последствия.
6. Указать статус proposed; пользователь утверждает переход в accepted.
7. Сослаться на связанные спецификации и предыдущие ADR.

Не реализовывать решение в рамках этого навыка.

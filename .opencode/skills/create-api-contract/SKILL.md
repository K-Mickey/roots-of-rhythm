# Create API contract

1. Прочитать story, существующий контракт, API-конвенции и changelog.
2. Проверить ресурсы, операции, авторизацию, идемпотентность, пагинацию и ошибки.
3. При неоднозначном публичном поведении остановиться и запросить решение.
4. Изменить минимальную часть OpenAPI, AsyncAPI или GraphQL-контракта.
5. Добавить реалистичные примеры и стабильные error codes.
6. Обновить каталог и changelog, если они существуют.
7. Запустить установленный contract-lint и diff.
8. Явно отметить breaking changes и не продолжать без подтверждения.

Не изменять production-код или тесты.

# Update graph schema

1. Проверить ADR и docs/architecture.md, подтверждающие использование графовой БД.
2. Если графового хранилища нет, остановиться: навык неприменим.
3. Прочитать текущую схему, ограничения, миграции и потребителей.
4. Описать изменение сущностей, связей, cardinality, индексов и совместимости.
5. Подготовить обратимую миграцию и план backfill или rollback.
6. Обновить схему, обзор, контракт и changelog синхронно.
7. Не выполнять migration в production без отдельного плана и подтверждения.

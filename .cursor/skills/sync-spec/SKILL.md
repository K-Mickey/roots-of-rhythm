# Sync spec

1. Прочитать исходный материал и текущую спецификацию полностью.
2. Составить перечень нового, изменённого, противоречащего и отсутствующего.
3. Не разрешать продуктовые противоречия самостоятельно; запросить решение.
4. Обновить цель, FR, NFR, acceptance criteria, границы и открытые вопросы.
5. Сохранить идентификаторы требований стабильными; новые добавить последовательно.
6. Не удалять требование без явного основания и записи изменения.
7. Проверить внутренние ссылки и перечислить смысловые изменения.

Результат: изменённая спецификация и краткий список изменений. Код, тесты, ветки и MR не трогать.

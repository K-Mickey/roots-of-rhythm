# /plan

Подготовить исполнимый план по утверждённой спецификации.

1. Сопоставить требования с существующей архитектурой и кодом.
2. Указать затрагиваемые файлы и границы компонентов.
3. Разбить работу на проверяемые шаги и зависимости.
4. Включить миграции, security, ошибки, документацию и проверки.
5. Не добавлять гипотетическую инфраструктуру.
6. Явно отметить действия, требующие подтверждения.

# /sync-tracker

Использовать навык `sync-github-tracker` для bootstrap или сверки GitHub Issues/Projects/Milestones с SDD-документами.

Сначала выполнить read-only inventory и показать dry run. Не выполнять внешние записи без явного подтверждения показанного batch и авторизованного GitHub-инструмента. Не закрывать, не удалять и не перемещать существующие items без отдельной команды.
